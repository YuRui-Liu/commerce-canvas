# 初始视觉系统

以已批准的 visual-directions-v3.html 作为视觉参考；本阶段只实现桌面初始壳，不把原型中的生成、保存、导入交互当作已完成能力。

| Token | A · 冷白钴蓝 | B · 纸白莓红 |
| --- | --- | --- |
| panel | #ffffff | #fffefd |
| canvas | #f0f2f5 | #eeecea |
| ink | #20242d | #272326 |
| accent | #3659df | #a9344e |

应用窗口初始 1440 × 960，最小 1024 × 720。布局为顶部品牌与主题切换、左侧素材栏、中间空画布、右侧创作助手与真实健康状态、底部本地环境状态。主题按钮支持键盘聚焦与 aria-pressed，健康状态使用 role=status。

图片是后续主角，当前不放置模拟商品图、模拟任务成功或可误用的伪按钮。导入、生成等未实现能力明确标注开发中。UI 不展示金额、账单与支付入口。

主题为当前会话状态；尚未实现主题偏好持久化。生产设计复核要求见 [production-ui-checklist.md](production-ui-checklist.md)。
