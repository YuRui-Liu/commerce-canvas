# 工作区内容与操作层次

供 C1–C4 实现；界面文案围绕商家的图片任务。工程壳的 SQLite/Sharp/版本号健康卡移到设置中的诊断区域，创作工作区不展示实现细节。

## 导航

顶栏：商品项目 / 画布 / 主题 / 设置 / 导出。左侧：素材 / Agent / 场景。右侧：创作助手 / 当前选中项。主题名称统一“白瓷钴蓝”“纸白莓红”，只提供这两种。

## 真实空状态

- 没有项目：“创建商品项目，把图片、SKU 和品牌资料放在一起。”按钮“创建项目”。
- 空画布：“拖入商品图片或文本，开始创作。”主操作“上传图片”，次操作“添加文本”“选择场景”。
- 无选中项：“选中画布上的素材，查看或编辑。”
- 对话输入提示：“例如：保留瓶身和标签，换成浅灰摄影棚背景。”示例只作 placeholder，不自动发送。
- 尚未配置模型：“连接创作助手后，可生成方案。”提供设置入口；本地素材编辑仍可使用。
- 没有生成作品：“生成的图片会保存在这里。”不放假成功状态或未经用户导入的商品图。

## 运行与数据反馈

- 保存：保存中 / 已保存 / 保存失败（重试）/ 内容已在另一处更新（重新载入或另存）。
- 图片导入失败：显示失败文件与原因，保留同批已导入文件。
- 方案确认：输入素材、操作、生成张数、每张最大修正次数；主操作“确认并开始”。
- 状态未知：“提交状态待核对”，已有 GRSai 任务 ID 可查询；没有 ID 时提示去 GRSai 核对，不能提供会自动重发的“重试”按钮。
- 原图与产物：“原图”“当前版本”“选用此版本”；切换查看不默认替换已选版本。
- 删除画布节点：“移出画布”；素材库软删除：“移入回收站”，避免两个动作语义混淆。

按钮显示真实可用状态；有暂不可用原因时就近说明。不在日常创作流程展示价格、余额、账单或充值入口。
