# 生产界面验收清单

来自专业 UI Designer 对已批准 A/B 原型的复核，2026-10-12。供 C1–C4 和最终视觉验收使用。

- A/B 强调色互斥；卡片白/纸白，成功状态只用小图标和短文案。连线 A #8D9DCA，B #B58E97。
- 主题仅作用于界面，商品图不能用滤镜、混合模式、透明蒙层或 currentColor；默认 contain，不暗中裁切。
- 正式产品移除原型评审横幅、色板和外围边距；顶栏 64–66px，导航 56px，素材约 224px，对话约 320px。
- 正文、输入、按钮 14px；节点标题 13px；元信息至少 12px；面板标题 14–16px/600；中文行高 1.6–1.8。
- 面板内边距 16–20px，节点 12–16px，控件间隔 8px，内容组间隔 16–24px。A 节点圆角 12px，B 7–8px；阴影仅用于浮动层。
- 节点内按钮与输入不触发画布拖动；drop 使用实际投放坐标；窗口 resize 不重置视角；用户主动“定位全部”才重新 fit。
- 对话与检查器共享节点上下文并保留各自草稿；运行确认展示张数和修正次数，无费用信息。
- 空画布提供上传图片/添加文本；无素材不显示资料已就绪。运行显示真实状态，失败保留输入及已有产物。
- 选择边框和键盘焦点分开；焦点 2px outline/3px offset；正文对比度至少 4.5:1。弹窗约束焦点，Esc 后归还；图标按钮命中区域至少 44px。
- 窄屏折叠/覆盖面板，不压缩全局字号或产生整页横向滚动；浮动工具条不遮挡侧栏。
- 悬停过渡 120–160ms，尊重 reduced-motion；商品图不做跳动动画，主题切换不重建画布。
- 原图对比共享比例和平移基准，标明版本，保持纵横比。
