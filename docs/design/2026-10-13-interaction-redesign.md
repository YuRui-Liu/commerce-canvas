# CommerceCanvas 交互重设计审查稿

日期：2026-10-13。状态：用户已确认“按 Nuomi 的交互方向实施”；素材删除缺失功能独立修复中。

## 代码审计结论

1. `packages/canvas/src/nodes/ImageGenerationNode.tsx` 不使用选中状态，常驻六个输入槽和完整参数表单，缺少图片主体。Nuomi 的 `frontend/src/features/canvas/nodes/ImageGenNode.tsx` 使用图片主体和选中时出现的下浮编辑面板；参考素材在面板中可逐一解绑。
2. `apps/desktop/src/renderer/generation/GenerationInspector.tsx` 又渲染一套 `GenerationControls`，形成重复编辑区域。`PhotographyDialog.tsx` 的十余项下拉表单缺少分组和视觉选择。
3. `packages/canvas/src/Canvas.tsx` 同时启用滚动平移和滚动缩放；普通素材也暴露六个角色输入点。素材库删除与画布移除概念未在操作入口区分。
4. `AssetLibrary.tsx` 没有删除回调，而 runtime 已有 trash/restore 能力；这是功能接线缺失。
5. `LeftRail.tsx` 的场景与 Agent 仅显示未接入提示。`docs/design/prompt-source-selection.md` 中的模板映射没有进入场景选择和实际出图配置，不能视为已实现。

## 布局方案与取舍

推荐采用 Nuomi 的图片主体＋选中编辑器。常用控制就在画布内，未选中节点保持紧凑；需要处理缩放、边缘遮挡和浮层焦点。

备选为常驻紧凑编辑器：学习成本低，但多节点画布仍拥挤。另一方案为参数全部置于右栏：画布最简洁，但频繁往返，不符合用户要求的 Nuomi 交互。

## 推荐方案

- 节点主体宽约 340 px，优先展示最新完成结果。未生成时展示简洁占位，已有输入时提供参考图摘要。图片保留原比例，以完整显示为默认。
- 仅选中时在节点下方展示编辑面板：第一行参考图缩略项及解绑操作；中间提示词；底部模型、画幅/分辨率、摄影、数量及生成按钮。右侧栏用于历史、结果及参数快照，避免再放重复表单。
- 参数按钮展示当前值，点击打开就近浮层。画幅用比例示意块，摄影按相机/镜头、构图、灯光分组；自动选项保持明确。应用、取消、Esc 和焦点返回行为一致。
- 参考图的解绑只删除连线；素材卡片以图片和输出端口为主。出图节点选中或连线期间显示带角色的输入端口，兼容现有图数据，不静默删除旧连线。
- 默认滚动平移、捏合缩放、空格或中键拖动画布、Shift 多选；工具栏提供缩放与适配视图。输入区的 Delete/Backspace 不影响节点。
- 素材库提供删除和撤销。删除使用回收站语义，现有画布引用与历史生成输入仍可读取；画布上的操作命名为“移除节点”，不混同素材删除。

### 交互实现约束

角色 Handle 保持原 ID 与固定几何位置，隐藏标签不卸载端口。下浮面板绝对定位，不进入节点测量，不因展开改变布局或视口。仅单选生成节点时展开，框选或多选不展开多张编辑器。

低于约 65% 缩放时提供固定屏幕尺寸的展开编辑入口；弹层在窗口边缘翻转定位或限高滚动。点击选中不自动抢提示词焦点。参数弹层关闭后焦点回到触发按钮，Esc 从最内层开始关闭。

输入区域消费 Delete、Backspace、撤销和滚轮；中文输入法组合期间不触发提交或画布快捷键。关闭双击缩放，图片双击用于原图查看。验收覆盖历史连线选中/取消、低缩放编辑、右下边缘弹层、中文输入法及 Esc 分层关闭。

## 让参考资料变成可用功能

场景入口首批提供白底主图、生活场景、材质细节、卖点海报。选择后实际创建或填入出图节点的可编辑提示词及摄影/画幅默认值，经现有确认与执行链路生成。覆盖已有输入前保留草稿或明确提示。

每个模板包含主体任务、构图、材质表达、文字、输出规格、约束。商品事实来自用户资料或输入引用，不预填虚构卖点。来源信息放在模板详情，记录已核验来源与版本。此稿依据仓库已有来源记录，不将其历史星数视为当前数据。

参考映射：白底主图对应 `product-commerce-visual`；生活场景与材质细节对应 `realistic-photography`；卖点海报对应 `poster-layout-system`。实现独立模板内容，不复制未经核验的图片或第三方商标。

## 验收

1. 实际桌面截图验证选中/未选中节点、双主题、多个节点、窄窗口与低缩放场景。
2. 参数更改、摄影应用/取消、连线/解绑、生成确认、输出查看形成完整可操作流程。
3. 素材删除后列表消失，撤销恢复；现有图片和文本节点、生成历史在重开后仍能读取引用。
4. 四个场景产生不同且可编辑的实际提交参数，不能只展示卡片或提示弹窗。
5. Electron 自动化按 AGENTS 要求使用隔离测试资料与隐藏窗口，不抢焦点。真实远端出图与模拟测试结果分别记录。

执行遵守当前仓库的单实现 Agent 工作流，完成后由独立 Agent 做规格与质量审查。
