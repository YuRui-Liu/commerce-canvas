# 画布出图节点与摄影参数设计

日期：2026-10-13。状态：用户已确认。本规格补充已批准的 CommerceCanvas 产品设计，聚焦画布内直接 GRSai 出图及摄影参数；不把所有 Agent/场景模块作为本次前置条件。

## 目标与方案

用户可以连接商品参考图，在出图节点内输入要求、选尺寸与摄影风格、确认张数并生成；结果成为新的不可变资产与画布输出节点，原图不被覆盖。保留现有白瓷钴蓝 / 纸白莓红主题。

比较三种布局：

1. **推荐：节点快捷参数＋弹层＋右侧完整参数。** 常用参数在节点就地操作，摄影弹层专注选择；右侧保留完整说明及任务记录。最贴近 Nuomi 现有工作方式，画布不会被长表单撑大。
2. 节点内展开全部参数：直观，但占画布面积大，多节点时干扰连线和比较。
3. 节点只显示预览，参数全部放右侧：最紧凑，但离开了用户要求的 Nuomi 式节点操作。

本规格按方案 1 设计。Nuomi 仅只读参考 `ImageGenNode.tsx`、`CameraPickerPopover.tsx` 与摄影选项契约；不复制 Elastic-2.0 源码、器材图片或全局 store。新节点独立实现。

## 节点与操作

- 工具栏提供“添加出图节点”；商品图、场景、风格和文本素材通过现有角色连线接入。节点显示输入缩略图及角色。无参考图时允许文生图，有商品图时按图生图处理。
- 节点包括标题/状态、提示词编辑区、模型、比例、分辨率、灯光、摄影、张数、生成按钮。参数按钮展示当前摘要；图片预览使用缩略图，查看原图复用现有查看器。
- 点击“生成”先保存最新节点配置并形成不可变输入快照。确认面板列出输入、模型、请求像素、张数；本阶段自动修正为 0 次，用户确认后才提交。默认 1 张，支持 1–4 张，各张独立任务。
- 参数弹层使用独立草稿，“应用”才写入节点，“取消”不改配置；“恢复默认”清除相应摄影约束。Esc 关闭并回到触发按钮。输入、滚动、选择参数不拖动节点、不触发画布 Delete。
- 小窗口弹层不超出视口，必要时改为可滚动对话框；不强行照搬 Nuomi 四列宽弹层。保留可读标签、键盘焦点和减少动画设置。
- 生成期间参数可以为下一次修改，但当前任务始终使用提交快照。节点显示任务所用参数摘要及“参数已修改”状态，禁止同一确认重复提交。

## 可选参数

| 分组 | 本次提供 | 执行语义 |
| --- | --- | --- |
| 模型 | gpt-image-2、gpt-image-2-vip | GRSai 实际 model；显示支持能力 |
| 构图比例 | 1:1、3:4、4:3、2:3、3:2、9:16、16:9 | 与模型的像素规格联动 |
| 分辨率 | 1K、2K、4K 档位；明确显示对应宽×高；VIP 支持自定义 | 1K/2K/4K 为预设名称，最终以显示的像素值为准 |
| 灯光 | 自动、柔光棚拍、窗边自然光、高调白底、硬光、高反差侧光、轮廓光、珠宝反光控制 | 编译为摄影要求 |
| 光线细调 | 光向（正面/左右45°/侧/顶/逆光）、软硬、暖/中性/冷、阴影强弱 | 编译为摄影要求，自动项不强加条件 |
| 相机 | 自动、商业全画幅、中画幅、手机生活感、电影摄影；自定义机身描述 | 风格参考，不声称真实设备、传感器或 EXIF |
| 镜头 | 自动、标准定焦、微距、广角、长焦 | 画面透视与细节要求 |
| 焦距 | 自动、24/35/50/85/100/135/200 mm；自定义 8–300 mm | 提示词描述，不保证光学数值被精确执行 |
| 光圈 | 自动、f/1.4、f/2、f/2.8、f/4、f/5.6、f/8、f/11、f/16 | 与景深描述一起编译 |
| 机位/景别 | 正面、45°、侧面、俯拍、低机位；全貌、近景、细节 | 摄影构图要求；缺真实背面参考不补造商品事实 |

默认摄影项均为自动，避免未知参数覆盖用户参考图。增加“白底主图”“生活方式场景”“微距细节”三个可解释摄影预设；选后仍可逐项调整，不改用户文案或输入角色。

## 模型能力与精确尺寸

- `gpt-image-2` 使用 `quality=auto` 和已核验的比例/1K 像素；2K、4K 显示为不可用并提示选择支持的模型，不自动替用户换模型。
- `gpt-image-2-vip` 使用 `quality=medium` 与像素参数。自定义尺寸要求两边为 16 的倍数，最大边 3840，长短边比不大于 3，总像素在 655360–8294400 之间；预设逐个按这些约束校验。
- 4K 方图使用受支持的 2880×2880，而非伪装支持 4096×4096。其他比例从核实的尺寸表选择，并显示完整像素值。
- 摄影参数只进入可查看的编译提示词，不作为 GRSai 未公开的 camera/focalLength/lighting JSON 字段提交。用户原始要求、商品事实、输入角色与摄影设置分段保留。
- 2026-10-13 实测请求 1024×1024 返回 1254×1254。因此成功下载后记录实际尺寸，不以服务端 succeeded 当成精确尺寸通过。原始产物始终保留；尺寸不一致时显示“原图尺寸与请求不一致”。
- 结果提供“适配为目标尺寸”：创建独立派生版本，选择完整保留/裁切；默认完整保留。等比例缩放后不足区域用用户选定背景补齐，不默认裁掉商品。派生版本标注为本地适配；不得声称原图原生符合请求或通过放大新增了细节。

## 执行与持久化

- 新增独立的出图节点配置 schema。配置、草稿与连线随画布保存，撤销/重做不删除资产或取消远端任务。
- 使用真正的 SQLite 任务记录接入 UI；不将之前的操作员验收 journal 充当生产调度。记录项目/画布/节点、不可变输入版本、完整参数快照、确认版本、槽位、尝试 ID、远端 ID、状态与产物引用。
- 确认和各槽位预占在事务中完成。同一确认 ID 重复点击返回原任务，不重复 POST；未确认或参数快照已变更不得沿用旧确认。
- Token 仍仅主进程通过系统安全存储解析。renderer 只得到脱敏状态；直接连接 GRSai 官方地址，无中转站，无价格/余额/账单界面。
- 提交前记录 submitting；已有远端 ID 只恢复查询。无 ID 的不确定提交进入“提交状态待核对”，不自动重发。可在用户核对后绑定经查询确认的任务 ID。
- 部分成功逐张展示；失败项可创建新的确认任务，不覆盖既有成功结果。停止按钮仅停止尚未提交的槽位；已提交任务明确仍可能完成，继续回收结果。
- 下载有上限、超时、解码/格式/像素校验与 hash，原子归档后才创建可查看的输出资产。下载失败只重试下载。
- 原图/派生输出节点带来源 run/slot/version，连到出图节点。重开软件可恢复任务和结果；切项目后任务继续属于原项目，不写入新画布。节点被删除时结果仍保存在原项目素材库和任务记录。

## 验证与完成标准

1. 单元/契约测试：模型参数兼容、摄影提示编译、快照隔离、确认预占并发、未知提交不重发、已知 ID 重启仅查询、部分成功和独立下载恢复。
2. 图像处理测试：原图 hash 不变、目标尺寸精确、完整保留与裁切可区分、派生版本来源可追溯。
3. 隐藏 Electron E2E：添加节点、连入真实本地素材、操作每组参数、应用/取消/键盘保护、保存重开、确认前无请求、双击确认不重复、状态及输出节点、未知状态提示、双主题与窄屏。
4. 真实 GRSai 验收继续按用户已有授权，选最小单张任务，通过实际画布入口验证。不得用模拟图称真实完成；不因尺寸差异自动再次生成。
5. 当前可见旧应用保持可用；完成后再提供新包。无需真实出图的自动测试仍用隐藏窗口，避免打扰用户。

本次不等待完整自定义 Agent 编辑器/LLM 三种适配器，不声称已实现全部电商场景、局部掩膜或自动修正。节点配置与任务契约为后续 Agent 调用保留复用入口。
