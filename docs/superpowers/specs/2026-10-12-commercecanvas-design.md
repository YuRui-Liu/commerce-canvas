# CommerceCanvas 产品设计规格

日期：2026-10-12。状态：设计与实现计划已批准，正在实施。2026-10-12 更新：用户明确改为直接接入 GRSai。

## 1. 产品定位与决定

CommerceCanvas 是面向电商商家、运营人员的独立图片创作工作台。以商品项目组织事实、SKU、素材和多个无限画布，通过总控对话与可连接的 Agent 节点制作商品图片。用户可以从场景模板开始，也可以在空白画布拖入图片、文本后创作。

项目目录：`/Users/liuyuxiang05/Liu/CommerceCanvas`。独立于 RedNote；复用 Nuomi-drama-factory 的画布能力，后续可接商品运营系统。

已确认的产品约束：

- 本地客户端管理资产、画布和 Agent，云端图片直接调用 GRSai，使用用户配置的 GRSai API Key。
- 支持 API 模式（包括 DeepSeek）和本机模式（Codex、WorkBuddy）。
- 自定义 Agent 以运行配置、LLM、Skills 和工具组成；提供开箱即用的电商预设。
- 首版交付包含全部列出的电商场景，各场景有专门交互与验收，不缩减为三条基础流程。
- 用户确认方案、生成张数及自动修正次数后执行；额外生成或超出修正次数需要重新确认。
- 不展示价格、余额金额、费用预估、消费标签、账单或计费明细；不建设中转站、号池或计费系统。
- 保留 A 白瓷与钴蓝、B 纸白与莓红两种可切换主题，A 默认，记住用户偏好。C 暗色方向不纳入已批准范围。

## 2. 商品项目与资产

项目包含商品事实、SKU、品牌规范、素材库、画布和产物版本。画布可以先创建，之后关联商品；开展依赖商品事实的任务前必须补足所需资料。

图片支持本地拖入、文件选择、粘贴、素材库拖入；批量导入生成多个节点。首批支持 PNG、JPEG、WebP，具体大小限制根据图片服务能力配置。文本支持拖入选中文字、粘贴和新建卡片。文本作为文本保存，不因拖入而自动执行指令。

资产角色分为商品依据、场景参考、风格参考、商品事实、任务要求、画面文案和交付作品。角色属于任务输入绑定：同一资产可以在不同任务中承担不同作用。商品依据优先于风格参考，不从风格图推断商品功能。

导入素材保存为本地受管文件，使用稳定资产 ID；原始素材不覆盖。用户替换输入、生成、修正均创建新版本。画布引用资产，删除节点不删除共享原始资产。资产库主动删除时检查引用并支持恢复。

## 3. 无限画布与双入口

基础节点包括图片、文本、Agent 任务、产物、分组。连线表示有角色的输入依赖；数据流采用有向无环图，修正循环属于任务内部，不在画布建立循环依赖。

支持平移、缩放、定位全部、框选、多选、对齐、分组、撤销重做、节点拖动和连线。点击选择，双击进入查看或编辑；节点标题可拖动，图片可放大。提供工具提示与键盘焦点，输入文字时快捷键不得误删节点。

框选资产后可交给指定 Agent，或在总控对话中引用选中资产。总控根据目标生成任务与依赖，呈现在同一画布；手动调整与对话调整操作相同的数据，不维护两份执行状态。

修改上游输入后，下游产物标记为需要更新。用户选择当前节点或受影响的下游范围重跑；旧作品和选用版本保留，执行结束后显式选择新版本。

## 4. 工作区与主题

布局：顶部为商品项目、画布切换、导出；左侧工具栏切换素材、Agent、场景，素材面板可收起；中央为无限画布；右侧默认总控对话，选中节点后可切换配置、文案编辑或图片检查。检查器和对话各自保留草稿与滚动位置，返回对话不丢失输入。

主界面围绕商品图片而非模型参数组织。运行方式、Skills 与工具权限在配置中可查，日常节点强调任务、状态和作品。

## 5. Agent、Skills 与工具

Agent 定义与任务实例分离。定义包含名称、职责、运行配置引用、系统指令、Skills 版本、允许的工具、输入输出约定及默认修正次数。用户可复制预设、创建自定义 Agent、编辑并另存；当前任务修改不会自动改写共享定义。

任务启动时保存 Agent、Skills、输入资产版本、商品事实版本及模型配置快照，使历史结果可追溯。凭证本身不写进快照。

API 模式由本地运行时负责模型消息、工具循环、上下文和输出解析。DeepSeek 是必需接入项，兼容 API 按服务方实际能力检测。图片理解不得默认所有文字模型都支持；需要视觉理解的任务必须使用具备相应能力的适配器或显式配置的视觉工具。

本机模式复用商家已安装、已登录的 Codex 或 WorkBuddy。适配器提供可用性检测、启动、进度、产物、取消和恢复能力说明，不假定两者 CLI 或协议相同。产品正式支持两种本机模式，但每个都必须经过真实接入验证；缺少安装或可靠接口时显示具体原因，允许切换 API 模式，不伪装为已接入。

Skills 包含清单、适用场景、必要输入、提示词模板、工作步骤、输出约定及验收规则。支持本地文件夹导入、浏览和版本化；从外部仓库选取的资料保留来源与许可信息。导入 Skill 不自动授权任意脚本执行。工具权限由本地执行层约束，外部 Skill 文本不能绕过任务张数和修正上限。

工具包括资产读取、商品资料读取、画布修改、图片图片服务调用、OCR／检查、局部编辑参数、确定性排版与导出。预设 Skills 借鉴高星资料的结构，不把未经核验的模板复制成商品事实。

## 6. 全场景交互与验收

| 场景 | 输入及专门交互 | 验收与失败处理 |
| --- | --- | --- |
| 精修／洗图、抠图、换背景 | 商品原图；涂抹修改区域和保护区域；前后对比 | 结构、边缘、透明区域、材质、文字与阴影；局部返修 |
| 融图、商品替换、道具调整 | 明确商品图／场景图；框选位置与遮挡关系 | 比例、透视、接触面、光向、遮挡，不改变商品身份 |
| SKU 换色、多角度 | SKU 列表、目标色映射、角度选择与多视图依据 | 非目标区域不变、配件和款式一致；缺失视角依据时标为未核验 |
| 模特换装、配饰试戴 | 模特素材、服饰或配饰资料、穿戴位置与保护区域 | 版型、纹理、人体关系、穿戴比例；问题区域标记与返修 |
| 主图、海报、卖点图 | 已确认文案、布局、品牌样式、平台规格 | 文字校验、信息层级、商品还原，不补写功效参数 |
| 详情页、套图 | 屏序、每屏目标、品牌规范、产品事实；逐屏和整套预览 | 跨屏一致性、卖点完整、单屏返修、连续长图拼接 |
| 结构拆解、尺寸参数图 | 必需的真实结构资料、尺寸和标注 | 不凭外观推造内部结构；缺必要资料则暂停索取 |
| 翻译、扩图、尺寸适配 | 翻译映射、保留文字、保护区域、裁切框、目标尺寸 | 漏译、错字、文字溢出、主体完整、尺寸准确 |

局部修改包含可撤销的区域绘制、保护区域及原图对比；掩膜和图片使用同一坐标基准，缩放不改变坐标含义。平台尺寸预设可配置，不在代码中假设永久有效。

详情页先规划屏序和文案，逐屏生成，允许调整排序、指定继承风格，再预览拼接。精确参数文字可使用可编辑文字层与确定性渲染，避免全部依赖模型在像素中写字。

每类场景都必须有端到端验收。模型或图片服务不具备必要能力时，入口显示不可用原因并说明所缺能力；此类状态不算该场景已交付，不能用模板占位宣称首版完成。

## 7. 执行确认与资源限制

任务流程：素材分析 → 方案草稿 → 用户确认 → 排队 → 执行 → 检查 → 有限修正 → 用户选用／导出。

确认页列出输入、操作、计划产物张数和每张自动修正次数。张数指首轮计划产物，修正单独计次；例如 2 张、每张最多修正 1 次，最多允许 2 次初始出图加 2 次修正出图。批量调用按实际请求输出张数预占，不能以一次 API 请求视作一张。

由本地调度器原子预占并记录剩余次数，多个 Agent 并发共享任务限额。图片服务只允许经过该工具入口提交。追加张数、扩大任务范围或增加修正上限需要用户确认新的计划版本；旧批准不覆盖新增动作。

运输层重试与新出图区分：本地 attempt ID 防止重复调度；已取得远端 ID 时只查询任务，未取得 ID 的提交超时标为状态未知并暂停，不能自动重发。不假定 GRSai 支持幂等键或按客户端标识找回。用户主动重跑属于新任务尝试，重新确认次数。取消操作停止本地未提交任务，并尝试取消远端；远端不支持取消时明确展示仍在执行，最终结果仍可回收。

不展示任何金额、价格或账单。额度不足时使用明确文案“可用额度不足，请联系服务方或补充额度”，与网络失败、鉴权失败、模型不支持分开。

## 8. GRSai 直接接入

本地可信运行时直接连接 GRSai，保存官方服务地址、模型与安全存储中的 API Key 引用。凭证不进入渲染器、Agent 提示词或日志。不建设自有代理、Token 包装、号池和账单系统。

统一新接口采用 Bearer 鉴权，异步生成 `POST /v1/api/generate`（`replyType: "async"`），取得任务 ID 后使用 `GET /v1/api/result?id=...` 查询。新旧协议不能混用；请求映射与能力限制记录在集成文档，并以官方资料和真实验收为准。

| 操作 | 必需语义 |
| --- | --- |
| 接入配置 | GRSai API Key、官方 API 地址与模型；无余额或账单字段 |
| 提交图片任务 | 模型、提示词、参考图片、比例和质量等已验证参数；本地任务 ID 不作为远端幂等保证 |
| 查询任务 | 按 GRSai 返回的任务 ID 查询状态与图片结果 |
| 获取产物 | 下载后校验格式与尺寸，保存本地不可变资产；失败重试下载，不重新生成 |
| 取消任务 | 先停止本地未提交任务；无已验证远端取消 API 时明确表示远端仍在执行 |

Asset Transport 仅使用 GRSai 已验证支持的图片传输格式，不把本地路径当远端 URL。多槽位分开提交，输出按任务 ID 绑定，避免错配 SKU。

恢复保证为“客户端不自动重复提交”：已有远端 ID 时恢复查询；提交是否受理不明且缺 ID 时保留预占和状态未知，提示用户去 GRSai 核对或补充任务 ID。上游未证明支持的幂等重放、按 key 找回、取消及模型发现 API 均不虚构。测试适配器通过不等于真实出图验收完成。

## 9. 模块、存储和数据流

| 模块 | 职责 | 依赖与接口 |
| --- | --- | --- |
| 商品与资产服务 | 事实、SKU、版本、文件与引用 | 本地数据库、文件存储；提供稳定 ID |
| 画布编辑器 | 节点、连线、分组、视口和选中状态 | 资产引用、任务读模型；不直接调用供应商 |
| Agent 注册与 Skills 库 | 定义、版本、工具权限、实例快照 | 配置与凭证引用；供运行适配器消费 |
| 任务编排器 | 计划、依赖、批准、次数预占、状态与恢复 | Agent 适配器、任务持久化、事件流 |
| Agent 适配层 | API／Codex／WorkBuddy 执行和能力检测 | 凭证存储、受控工具接口 |
| 图片图片服务适配层 | 上传、提交、查询、下载、错误映射 | GRSai 与本地资产服务 |
| 检查与导出 | 质量问题、局部返修、拼接和平台尺寸输出 | 产物版本、事实快照、图像处理工具 |

核心实体：ProductProject、SKU、BrandProfile、Asset、AssetVersion、Canvas、Node、Edge、AgentDefinition、SkillVersion、RunPlan、Run、RunAttempt、OutputVersion、InspectionIssue。任务批准绑定计划版本，产物绑定输入与 Agent 快照。

本地采用事务数据库保存业务数据、任务日志与版本，文件系统保存图片；敏感凭证通过系统安全存储及本地凭证服务隔离，前端只接触脱敏引用。画布位置变化合并保存，任务关键状态即时事务落盘。浏览器自动化原型中的状态不作为存储设计依据。

首选复用方向为 React + TypeScript、React Flow 与 Zustand；本地客户端壳和运行服务具体技术选择属于实现计划，应以本机进程接入、打包及凭证能力验证决定，产品模块接口不依赖具体壳。

## 11. 失败、恢复与数据保护

任务状态至少区分：草稿、待确认、排队、执行、检查、修正、部分成功、成功、失败、待补资料、取消中、已取消、远端状态未知。恢复不能把未知状态直接当作失败并重发。

重启后读取未完成尝试，按远端 ID 查询并归档成功产物，保留部分结果。已提交但未记录 ID 的尝试进入状态未知并停止自动提交，等待用户核对远端任务。

网络中断、本机 Agent 退出、能力不支持、输入缺失、Token 失效和额度不足分别显示可操作的说明。用户可以重试失败项或改用其他已配置适配器，不能偷偷更换模型或修改商品事实。

外部素材内容与 Skill 内容不授予执行权限；本机任务仅访问该项目与明确授权资产。日志屏蔽 Token，导出不包含凭证。项目备份包含数据库和对应资产，恢复时校验引用完整性。

## 12. 验收与分模块交付

产品范围较大，按独立模块安排实施和验收，最终首版仍需覆盖全部场景。依赖顺序为：基础资产与画布 → Agent 与任务编排 → 图片服务接入与恢复 → 全场景操作 → 检查导出 → 综合验收。

必须通过的验收：

1. 图片／文本拖入、粘贴、多选、连线、撤销与保存恢复；删除节点不损坏原始素材。
2. A／B 切换持久化，图片和导出不受主题影响；可见焦点、文字对比和窄窗口操作无阻断。
3. 预设与自定义 Agent、实例配置隔离、Skills 版本追踪；DeepSeek、Codex、WorkBuddy 分别真实验证。
4. 总控与画布共享状态；上游改动使下游失效，局部重跑保留已选版本。
5. 并发运行不突破确认张数与修正上限；超时、重启、重复响应不触发重复生成；取消语义符合图片服务能力。
6. 第 6 节每类场景都有真实素材的成功和失败用例；自动检查发现的问题可定位、返修，不能保证模型绝对正确。
7. 详情页逐屏编辑、排序、拼接、批量 SKU 与平台尺寸导出；结果文件可打开、尺寸和文案正确。
8. 图片服务额度不足与错误分类准确；产品中无费用与账单界面，底层真实调用可追踪。

测试优先覆盖状态机、次数并发预占、状态恢复、版本失效、输入绑定和导出尺寸；浏览器验证覆盖真实用户操作。真实供应商与本机适配器使用各自验收证据，不用模拟测试代替。
